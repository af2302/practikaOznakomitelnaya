# Музыкальная программа (вариант 2)

Оконное приложение на C++20 и Qt 6 Widgets: порядок музыкальных номеров мероприятия.

## Окружение (заполнить своими значениями)
- ОС: ...
- Компилятор: ...
- CMake: ...
- Qt: 6.x.x (Widgets, Test)
- Стандарт C++: 20

## Сборка и запуск
```
cmake -S . -B build -DCMAKE_PREFIX_PATH=<путь к установленному Qt>
cmake --build build
./build/music_app
```
## Тесты
```
cd build
ctest --output-on-failure
```
## Устройство
- `src/Program` - предметная логика (`std::deque<Track>`), без виджетов.
- `src/Storage` - JSON (QJsonDocument), запись через QSaveFile, полная проверка при чтении.
- `src/MainWindow` - окно; данные хранятся только в `Program`.
- `tests/tst_music.cpp` - 18 сценариев Qt Test, зарегистрированы в CTest.

## Формат файла
```
{"formatVersion":1,"variant":2,
 "state":{"tracks":[{"code":1,"title":"...","artist":"...","duration":120}]}}
```
`tracks` - номера в текущем порядке. Код 1..1000000 и уникален, название и исполнитель 1..100 символов после удаления внешних пробелов, duration 1..86400, не более 1000 номеров, файл не более 1 МиБ. Неизвестные поля игнорируются.

Примеры: `data/sample.json` (корректный), `bad_*.json` и `broken.json` (должны отклоняться).

## Известные ограничения
Только локальная работа; собиралось и проверялось на одной ОС (указать выше).
