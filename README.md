# Музыкальная программа

Учебный проект по ознакомительной практике — приложение «Музыкальная программа», вариант 2.

Программа реализована на C++20 с использованием Qt 6 Widgets. Для хранения основной коллекции применяется `std::deque`, для сохранения и загрузки данных — формат JSON.

## Технологии

- C++20.
- Qt 6 Widgets — графический интерфейс.
- Qt Test — автоматические тесты.
- CMake — конфигурация сборки.
- Ninja — система сборки.
- MSYS2 MINGW64 — рабочее окружение Windows.
- Git — контроль версий.

Проект собирался и проверялся на Windows 11. Версия CMake в рабочем окружении — 4.4.5.

## Архитектура

Программа разделена на три основных компонента:

| Компонент | Назначение |
|---|---|
| `Program` | Предметная логика и работа с основной коллекцией `std::deque` |
| `Storage` | Загрузка, проверка и сохранение данных в формате JSON |
| `MainWindow` | Графический интерфейс и обработка действий пользователя |

Для записи файлов используется `QSaveFile`.

## Требования для сборки

- Windows с установленным MSYS2.
- Окружение MSYS2 MINGW64.
- Компилятор GCC с поддержкой C++20.
- Qt 6 с модулями Widgets и Test.
- CMake.
- Ninja.
- Git — для клонирования репозитория.

Команды ниже необходимо выполнять в терминале MSYS2 MINGW64.

## Получение проекта

```bash
git clone [https://github.com/af2302/practikaOznakomitelnaya.git](https://github.com/af2302/practikaOznakomitelnaya.git)
cd practikaOznakomitelnaya
```

Если проект уже находится на компьютере, перейдите в его корневую папку — каталог с файлом `CMakeLists.txt`.

## Сборка

Из корневой папки проекта выполните:

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## Запуск приложения

Из корневой папки проекта:

```bash
./build/music_app.exe
```

Либо из каталога сборки:

```bash
cd build
./music_app.exe
```

Запуск в рабочем окружении выполняется из терминала MSYS2 MINGW64. При запуске непосредственно через Проводник Windows может появиться сообщение об отсутствии библиотек среды выполнения, если они недоступны в окружении Windows.

## Автоматическое тестирование

После сборки выполните из корневой папки проекта:

```bash
ctest --test-dir build --output-on-failure
```

Тестовую программу также можно запустить напрямую:

```bash
./build/tst_music.exe
```

Зафиксированный результат запуска Qt Test:

```text
Totals: 20 passed, 0 failed
```

В результат входят 18 тестовых сценариев и два служебных шага Qt Test: `initTestCase()` и `cleanupTestCase()`.

Дополнительно выполнена ручная проверка интерфейса приложения.

## Работа с данными

Данные сохраняются в формате JSON. Компонент `Storage` отвечает за чтение файла, проверку входных данных и сохранение результата.

Для безопасной записи применяется `QSaveFile`.
